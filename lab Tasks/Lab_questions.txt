Problem Description:

Implement the 0/1 Knapsack algorithm in two ways:

Using simple recursion (without memoization).
Using dynamic programming with memoization (top-down approach).

Run both implementations on the same set of test cases, measure their execution times, and compare the results. Analyze how memoization reduces redundant computations and improves the overall runtime compared to the naive recursive approach.

Test Case Guidelines:

Create at least 10 test cases with varying numbers of items (e.g., 5 to 35 items) and different knapsack capacities.
Include small, medium, and large inputs to demonstrate the performance difference.
Generate item weights and values randomly or design them manually, ensuring all weights and values are positive integers.
Use the same test cases for both implementations to ensure a fair runtime comparison.
Record the execution time for each test case and present the results in a table or graph.

A. Dijkstra
CPU: 1s
Memory: 512MB
Given an undirected weighted graph find shortest path of each node from the node 0.

Input
First Line: N ( 0<N<=100000), number of nodes. Second Line: M ( 0<N<=300000), number of edges. Next M lines, each: U V W(0<=U, V<N), defines an edge between U and V with weight W.

Output
Shortest path of each node. If any node is not reachable, print Infinity. See sample for clarification.

Sample
Input

7
6
1 3 2
1 2 5
0 1 3
3 2 1
3 4 50
2 5 10

Output

0: 0
1: 3
2: 6
3: 5
4: 55
5: 16
6: Infinity
